# 평가계획 정보공시

초등 교수·학습 및 평가계획의 정보공시 적합성을 판정하고 원본 형식을 보존한 개정 HWP를 만든다.

## 기준 확인

작업 전에 [references/2026-elementary-revisions.md](references/2026-elementary-revisions.md)를 전부 읽는다. 사용자가 별도 개정 안내나 지침서를 제공하면 그 문서를 우선 기준으로 삼고, 참고문서와 충돌하는 부분을 명시한다.

## 작업 흐름

1. 제공된 안내문과 평가계획을 모두 연다. HWP/HWPX는 한글 COM 자동화가 있으면 `GetTextFile("TEXT", "")`로 텍스트를 추출하고 PDF로 내보내 표 구조도 확인한다.
2. 현재 열을 필수 항목과 대조한다. 내용상 동등한 `평가시기`는 `시기`로 인정하되, 공식 복합 표제는 정확히 맞춘다.
3. 원본을 수정하지 않는다. 새 파일명에 `_개정양식`, `_정보공시용` 등 목적을 드러내는 접미사를 붙인다.
4. 다음 공식 표제를 기본으로 사용한다.
   - `평가시기`
   - `단원명(교수·학습 내용)`
   - `평가 요소`
   - `평가 영역`
   - `평가 방법 및 횟수`
   - `성취기준`
   - `성취수준`
5. `수업 방법`, `수업·평가 연계의 주안점`은 새 정보공시 표에서 제거한다. 개정 전·후 비교 예시라면 개정 전 표는 보존한다.
   - `[토의·토론 수업]`, `[탐구 학습]`, `[활동 중심 학습]`, `[역할극]` 같은 괄호형 수업 방법명은 삭제한다.
   - 수업 방법명 뒤에 있는 실제 학습 활동 문장만 `단원명(교수·학습 내용)`으로 옮긴다.
   - 수업 방법명 자체를 교수·학습 내용으로 옮기지 않는다.
6. `평가 기준`을 단순히 제목만 `성취수준`으로 바꾸지 말고, 각 단계 설명이 성취기준 도달 정도를 나타내는지 확인한다. 성취수준의 종결 어미는 능력 가능형 `~할 수 있다`보다 수행을 직접 서술하는 `~한다·읽는다·쓴다·표현한다`형으로 재구성한다.
7. 평가 횟수는 근거가 있을 때만 기입한다. 한 행이 한 번의 평가임이 명백한 예시는 `관찰 평가 / 1회`처럼 쓸 수 있다. 실제 계획의 횟수가 불명확하면 임의로 전부 `1회` 처리하지 말고 사용자에게 확인하거나 미확정 항목으로 보고한다.
8. 표 안의 공식 용어, 공백, 가운데점 `·`, 괄호를 함께 점검한다.

## HWP 자동화

Windows와 한글이 설치된 환경에서는 다음 순서를 사용한다.

1. 워크스페이스 의존성을 불러와 번들 Python 경로를 확인한다.
2. `scripts/revise_hwp.ps1`에 원본 HWP, 결과 HWP, Python 실행 파일을 전달한다.
3. 스크립트가 만든 HWP를 다시 열어 표제 변경을 확인한다.
4. 각 평가 행의 실제 횟수는 문서 근거에 따라 채운다.

```powershell
& scripts/revise_hwp.ps1 `
  -InputPath "원본.hwp" `
  -OutputPath "결과_개정양식.hwp" `
  -PythonExe "번들-python.exe"
```

입력이 HWPX이면 `scripts/update_hwpx_headers.py`를 직접 실행한다.

```powershell
& "번들-python.exe" scripts/update_hwpx_headers.py 원본.hwpx 수정.hwpx
```

한글 COM을 사용할 수 없으면 HWP를 억지로 변환하지 않는다. 사용자에게 HWPX로 다시 저장한 파일을 요청하거나, 사용 가능한 문서 변환기로 복사본을 변환한다.

## 검증

완료 전에 다음을 모두 확인한다.

- 결과 HWP를 한글로 다시 열 수 있음
- `단원명(교수·학습 내용)`과 `평가 방법 및 횟수`가 존재함
- 새 표에 `수업·평가 연계의 주안점`과 `평가 기준`이 남아 있지 않음
- `단원명(교수·학습 내용)`에 괄호형 수업 방법명이 남아 있지 않고 실제 활동 내용은 보존됨
- 성취수준 설명의 종결 어미에 `~할 수 있다`형이 남아 있지 않음
- 평가 횟수가 누락되거나 근거 없이 일괄 입력되지 않음
- PDF로 내보내 모든 페이지를 확인했으며 표 잘림, 겹침, 과도한 줄바꿈이 없음
- 원본 파일이 보존됨

최종 답변에는 변경 내용과 검증 결과를 짧게 밝히고 결과 HWP만 연결한다. 중간 HWPX, PDF, PNG는 사용자가 요청하지 않는 한 제공하지 않는다.
